# Classroom Seat Master

免伺服器、免資料庫的班級座位編排工具。直接雙擊 `index.html` 即可離線使用，設定會自動保存在目前瀏覽器的 `localStorage`。

## 功能

- 動態設定 1–10 行、1–12 排座位網格
- 班級名稱、學生數、缺號與座位尺寸均為執行時設定，非固定在程式碼
- 增減網格時保留仍存在位置的座位狀態，新增位置自動建立為不限座位
- 不限、男生、女生、走道四態座位
- 單格、整行、整排快速設定
- 最大座號、缺號區間、女生起始座號自動解析
- 「學生資料」支援座號、姓名及老師自訂的任意欄位，例如外號、帳號、密碼、居住地點
- 可直接貼上 Excel／試算表；第一列作為欄名，自動依座號同步最大座號與缺號，忽略空白座號列並保留所有自訂欄位
- 展示模式點擊學生座位會開啟 3D 翻牌資料卡；密碼類欄位預設遮罩，可再點擊顯示
- 展示可切換純座號、純姓名、座號＋姓名；缺姓名時自動回退座號
- 管理介面與展示模式可即時切換繁體中文／English，班名及姓名維持原文
- 固定特殊座位，展示模式完全隱藏規則與標記
- 「事先安排」暗樁模式可直接點座位指定特殊生，抽籤保證保留預排位置
- 抽籤後自動進入「調整結果」，依序點兩個座位即可交換學生或空桌
- 手動調整後可直接返回展示，不會重新抽籤；最終結果會保存在本機與匯出檔
- 使用瀏覽器加密亂數進行公平洗牌
- 展示模式含倒數、座位翻滾、落定慶祝動畫與離線合成音效
- 音效可隨時開關，不需下載或連線外部音訊
- JSON 設定匯入、匯出與本機自動儲存

## 專案結構

```text
SeatPlanner/
├── index.html             # 頁面骨架
├── assets/styles.css      # 完整視覺與響應式樣式
├── js/constants.js        # 常數與預設狀態
├── js/i18n.js             # 繁中／英文語系字典與切換
├── js/storage.js          # 本機儲存及匯入匯出
├── js/seat-engine.js      # 名單解析、驗證、隨機排位
├── js/ui.js               # DOM 渲染
├── js/sound.js            # Web Audio 離線音效
├── js/app.js              # 狀態管理與事件協調
└── tests/engine.test.js   # 無相依套件的引擎測試
```

## 測試

需要 Node.js 18 以上：

```bash
node tests/engine.test.js
```

## 使用注意

- 更換瀏覽器或清除網站資料前，建議先按「匯出設定」。
- 學生資料只保存在目前瀏覽器與使用者主動匯出的 JSON；密碼雖預設遮罩，仍請避免輸入不宜在教室展示的敏感資訊。
- 固定座位屬於教學管理資訊；對學生展示前請使用「進入展示模式」。
- 展示模式不顯示性別顏色、限制類型或固定標記，所有有效座位使用相同動畫。
