# SeatPlanner Inclusive 2.0

免伺服器、免資料庫的班級座位編排工具。直接雙擊 `index.html` 即可離線使用，設定會自動保存在目前瀏覽器的 `localStorage`。

兼顧全班與個別學習需要的座位及合作學習工具。首次開啟顯示指定教室主視覺與五步教學；完成、略過或開始真實編輯後不再自動顯示。頁首「？操作教學」可隨時重看，保留全部班級與結果。

快速操作：建立／匯入班級 → 規劃教室 → 優先安排 → 手排或展示後抽籤 → 展示與備份。首頁進度使用真實學生、座位及優先安排人數；性別座位配置、標記與旋轉收在「進階設定」。

完整使用方式見 [操作指南](docs/inclusive-2.0-guide.md)，各階段實作與驗收見 [交付報告](docs/inclusive-2.0-delivery.md)。本地改版不代表正式投稿版本已替換。

## 功能

- 首頁為座位設定頁；各模式都有固定「回首頁」按鈕，抽學生／指定座位／資料卡視窗也可直接返回，保留手動草稿與完成結果
- 動態設定 1–12 行、1–12 排座位網格
- 班級名稱、學生數、缺號與座位尺寸均為執行時設定，非固定在程式碼
- 可在「目前班級」切換、新增、複製或刪除班級；每班各自保存名單、座位版型與抽籤結果
- 增減網格時保留仍存在位置的座位狀態，新增位置自動建立為不限座位
- 管理與展示模式皆可順時針或逆時針旋轉整間教室 90°，學生座位、黑板、門、老師座位、走道、性別限制、預排座位與已抽結果完整跟著旋轉
- 黑板、教室門與老師座位可分別配置於教室四周 12 個位置，亦可單獨隱藏；黑板支援五段長度，門與老師座位可再做 ±60 px 微調
- 不限、男生、女生、走道四態座位
- 男女座位可一鍵套用橫排交錯、直行交錯或棋盤交錯；保留走道，並依實際男女比例自動留下必要的不限座位
- 單格、整行、整排快速設定
- 最大座號、缺號區間、女生起始座號自動解析
- 「學生資料」支援座號、姓名及既有自訂欄位；請勿新增密碼、地址、診斷或聯絡資料
- 可直接貼上 Excel／試算表；第一列作為欄名，自動依座號同步最大座號與缺號，忽略空白座號列並保留所有自訂欄位
- 展示模式點擊學生座位會開啟資料卡，僅顯示座號與姓名，不將自訂欄位放入公開資料卡 DOM
- 展示可切換純座號、純姓名、座號＋姓名；缺姓名時自動回退座號
- 管理介面與展示模式可即時切換繁體中文／English，班名及姓名維持原文
- 保留需要的位置，展示模式隱藏座位限制與保留標記
- 「優先安排」可先為學生保留位置，抽籤沿用保留位置，無需記錄個別理由
- 「全手動排位」不必先抽籤：選學生後點座位，預設自動接續下一位；支援姓名／座號搜尋、拖曳、鍵盤、交換、移回待排與復原／重做
- 手動草稿可重載接續並隨 JSON 匯出；全班排好後直接完成展示，走道不可排位，其餘由老師自由決定
- 抽籤後自動進入「調整結果」，依序點兩個座位即可交換學生或空桌
- 維護後台以「點此開始展示」進入投影畫面，展示畫面以「返回維護後台」回到設定
- 使用瀏覽器加密亂數進行公平洗牌
- 展示模式含聚光倒數、座位翻滾、漸快鼓聲、揭曉和弦與彩紙動畫；可直接揭曉，並配合系統減少動態效果設定
- 管理與展示模式都可按「抽學生」，使用現有有效名單一次抽一位或多位；預設本輪不重複，可切換允許跨次重複
- 抽學生支援名牌翻動、得獎卡片、本輪紀錄、重開一輪及瀏覽器自動儲存；缺號不參加，座位限制不影響抽學生
- 關閉尚未揭曉的抽學生活動不會扣除名額；座位重抽中途退出會保留上一次已揭曉的結果
- 音效可隨時開關，不需下載或連線外部音訊
- JSON 設定匯入、匯出與本機自動儲存；v4 備份可一次包含多個班級，舊版單班級檔仍可匯入。未改動預設 601 班時，首次匯入會直接取代示範班級。
- 無實體座位名單仍參加班級活動；座位容量、預排、抽座位與手排完成條件只計需座位學生
- 自由教室版型：島型小組桌、圓桌、U 型桌與主要通道。島型初始配置避開中央通道；後續移動與旋轉可能造成重疊，介面提供提醒。先選取畫布物件再使用分區設定面板，可拖移、旋轉、複製桌組及調整座位數；數值欄位也能以鍵盤調整。通道是規劃輔助，須現場確認
- 臨時任務分組：全班 2–6 人、隨機／男女均衡／同性別策略、預排成員與桌位、手動移組、鎖定後重抽、復原／重做及列印
- 活動名冊與結果獨立保存並包含在 v4 JSON 備份中，不覆蓋日常座位結果
- 教師端選填環境提醒、依最近五次活動的同儕輪替提醒、空白可列印觀察表；不推斷診斷或宣稱教學成效
- 展示可切換少動畫與高對比大字，預設靜音並配合系統減少動態效果設定
- 完整本機備份保留舊欄位；去敏座位表只含座號與位置，不含姓名、自訂欄位或優先安排標記，座號仍可能被識別

## 資料保存與首次使用

工作資料繼續使用 `classroom-seat-master:v4` 與 JSON v4，維持 v1–v3 單班級檔案遷移。教學旗標另存 `seatplanner:ui-onboarding:v1`，不放入備份 JSON。初始化自動建立的 601 班不算真實活動。若舊用戶資料剛好完全等同預設示範，可能仍看見一次可略過教學；不會因此清除工作資料。

儲存失敗會顯示「請立即匯出備份」；讀取損壞資料時暫停覆寫，原始值保留。請先保存備份，再明確重設恢復儲存。瀏覽器資料並非加密保險箱；本程式不能自動掃描裝置上的資料夾。匯入由使用者選擇 JSON，驗證後預覽班級數及學生數；非示範班級保留並合併，無效整批拒絕。

刪班、清除保留位置及全部重設可在本次頁面關閉前使用「復原資料操作」；桌位變更另有復原／重做。減少座位時保留其他學生的位置，衝突學生回到手排待排名單。復原紀錄只留在記憶體，請另做完整備份。一般刪班不重設教學；「重設全部與教學」會重顯歡迎。

已移除外部統計腳本，不依賴 CDN、帳號或雲端。主視覺 PNG 內含中文字，英文介面提供可讀 HTML 等價文案，圖中文字仍保留。

## 開發與驗證

不需 npm 或前端建置。測試需要 Node.js；瀏覽器測試另需 Python、Playwright 與 Chromium：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install playwright
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe -X utf8 tests/run-tests.py --browser
```

只跑 Node 測試：`python tests/run-tests.py`。報告與截圖輸出到忽略版控的 `test-results/`；合成資料位於 `tests/fixtures/`。沒有安裝瀏覽器時不可把單元測試當作 E2E 通過。真實教師試用及完整無障礙稽核尚待進行。

## 專案結構

```text
SeatPlanner/
├── index.html             # 頁面骨架
├── assets/styles.css      # 完整視覺與響應式樣式
├── js/constants.js        # 常數與預設狀態
├── js/i18n.js             # 繁中／英文語系字典與切換
├── js/storage.js          # 本機儲存及匯入匯出
├── js/seat-engine.js      # 名單解析、驗證、隨機排位
├── js/ui.js               # DOM 渲染
├── js/sound.js            # Web Audio 離線音效
├── js/draw-effects.js     # 共用倒數、音效、揭曉與取消時序
├── js/student-draw.js     # 抽學生、本輪名單及紀錄
├── js/manual-seating.js  # 手動草稿、名單操作與復原／重做
├── js/group-planner.js    # 任務分組與公平分組規則
├── js/group-ui.js         # 任務建立、座位指派、復原與列印
├── js/room-layout.js      # 自由教室版型與座位幾何
├── js/app.js              # 狀態管理與事件協調
└── tests/                # Node 單元測試與 Playwright 瀏覽器流程
```

## 測試

需要 Node.js 18 以上：

```bash
node tests/engine.test.js
node tests/effects.test.js
node tests/manual.test.js
node tests/group-planner.test.js
node tests/room-layout.test.js
```

完整瀏覽器驗證（需 Python Playwright 與 Chromium）：`python tests/manual-browser.py`。
新功能瀏覽器流程（同樣需要 Playwright 與 Chromium）：`python tests/features-browser.py`。

手動排位操作、設計理由與資料行為見 [操作設計](docs/manual-seating.md)。

功能規格與驗收範圍見 [增功能計畫](docs/feature-plan-2026-10.md)。

自由教室座位重疊、桌位容量與單席位置編輯改善提案見 [教室版面改善計畫](docs/room-layout-improvement-plan.md)。

## 使用注意

- 更換瀏覽器或清除網站資料前，建議先按「匯出設定」。
- 抽學生紀錄另外保存在目前瀏覽器，不包含於座位設定匯出檔；班名或有效名單（含姓名）改變時會開始新一輪。
- 學生資料只保存在目前瀏覽器與使用者主動匯出的 JSON；展示資料卡不提供自訂欄位揭露按鈕，完整備份仍保留舊欄位，請避免輸入敏感資訊。
- 固定座位屬於教學管理資訊；對學生展示前請使用「點此開始展示」。
- 展示模式不顯示性別顏色、限制類型或固定標記，所有有效座位使用相同動畫。
