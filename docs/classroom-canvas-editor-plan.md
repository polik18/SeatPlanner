# 教室標記與外框視覺編輯改版計畫

狀態：已完成第一版實作與自動化驗證；教師首次使用試用尚待進行。操作及資料格式說明見 [教室畫布編輯器](classroom-canvas-editor-guide.md)。

## 一、目標與範圍

讓老師像在繪圖軟體中操作幾何圖形：直接在教室圖上點選、拖動、縮放與旋轉黑板、門、老師座位，也能直接調整教室形狀寬高比。主要流程不再依賴位置下拉選單與多個拉霸。

保留核心教學用途：這些操作是教師私下規劃教室的工具，不改變學生身分、預排座位、分開規則與已完成的排位。展示模式僅呈現編輯結果。

本期外框以可調寬高的矩形為限；L 型、多邊形、凹角教室另列後續需求。使用者提出的「調整寬比」納入為可自由調整寬高比，而不只橫向／直向切換。

## 二、現況研究

| 現況 | 使用困難 | 改版方向 |
| --- | --- | --- |
| 黑板、門、老師座位共有 3 個位置下拉選單、7 個拉霸 | 必須在側欄調整，再到教室圖確認；長度與大小的區別不明顯 | 直接拖移與拉控制點，選中後才出現少量工具 |
| 各標記使用四邊共 12 個固定位置，加上偏移量 | 無法直接放到任意位置，方向由邊緣樣式決定 | 各標記有獨立的位置、寬高與角度 |
| 黑板的桌面、側邊與手機長度使用不同像素公式 | 不同裝置的幾何比例不一致 | 統一教室座標，畫面只做等比例縮放 |
| `.room-edge` 使用 `pointer-events: none` | 現有標記無法直接選取與拖曳 | 新增可互動標記層，限定在編輯模式接受操作 |
| 桌組、座位及通道已有 Pointer Events 拖曳 | 可參考現有事件處理，但標記位於 `seatGrid` 外，不能直接套上 | 抽出共同座標與拖曳工具，標記使用獨立控制器 |
| 教室外觀目前是橫向／直向，CSS 預設約 4:3 | 無法反映較寬或較狹長的教室 | 外框可拖曳，也可選比例或輸入寬高 |
| 網格與自由桌型的整間旋轉走不同程式路徑 | 新標記容易只在其中一種版型正確旋轉 | 統一標記與外框的旋轉規則，兩條路徑皆驗證 |

主要程式位置：`index.html` 的 `.room-marker-settings`；`js/ui.js` 的 `renderRoomMarkers()`；`js/app.js` 的 `updateRoomMarkersFromInputs()`、`rotateLayout()` 與畫布指標事件；`js/seat-engine.js` 的設定正規化與旋轉；`assets/styles.css` 的 `.room-layout`、`.room-edge`、`.room-marker`。

## 三、老師看到的操作

### 1. 單一編輯入口

在教室圖上方放「編輯教室」按鈕，進入後顯示清楚的編輯邊框與「完成編輯」。現有桌組編輯狀態整合到同一入口，避免同時存在兩個意義相近的開關。

工具列初期只放：選取、黑板、門、老師座位、教室形狀、復原、重做、完成。黑板／門／老師座位按鈕會選取既有物件；若物件已隱藏，則在可見區恢復並選取。首版仍各一個，不額外擴張為任意數量與圖形庫。

進入編輯後暫停座位點選的預排、交換與學生資料卡操作。退出後清除選取與控制點，恢復原操作。未儲存的拖曳不能在模式切換時留下半完成狀態。

### 2. 點選標記，就地編輯

| 動作 | 行為 |
| --- | --- |
| 點選黑板、門、老師座位 | 顯示選取框、縮放控制點與旋轉把手 |
| 拖物件本體 | 直接移動，顯示對齊參考線 |
| 拉左右／上下控制點 | 改寬度／高度 |
| 拉四角控制點 | 同時改寬高；工具列提供「鎖定比例」 |
| 拖旋轉把手 | 以中心旋轉，顯示角度；接近 0°／90°／180°／270°時吸附 |
| 點旁邊的精簡工具列 | 左轉 90°、右轉 90°、隱藏、重設此標記 |
| 點空白處或按 Esc | 取消選取；若正在拖曳，Esc 先取消當次拖曳 |

黑板與門以簡單幾何外觀表示，老師座位用簡單桌面外觀。位置與方向由物件幾何呈現，文字標籤維持易讀，不因旋轉變成倒字；標籤字級與可點區有下限，避免縮小物件就看不清楚。

門與黑板靠近牆面時提供吸附預覽；門預設貼牆移動，選中後可關閉貼牆。老師座位可放教室內部。貼牆不再要求選「左上／左中／左下」等位置。

「精確設定」摺疊區只在選中物件時出現，提供位置、寬高、角度輸入，作為鍵盤操作與精修的補充。一般老師可以全程不用開啟。

### 3. 教室形狀也能拉寬、拉高

選「教室形狀」後，外框出現邊與角的控制點，並顯示「寬：高」。外框控制點與物件控制點採不同顏色，且不會同時顯示。

- 拉右邊／左邊：改變教室寬度。
- 拉上邊／下邊：改變教室高度。
- 拉四角：同時調整寬高；啟用比例鎖定時維持原比例。
- 提供常用比例按鈕：4:3、16:9、1:1、3:4，以及自訂寬高輸入。
- 寬高使用「比例單位」，不標為公尺，避免讓使用者誤以為是經過校準的實際尺寸圖。
- 拖曳時即時顯示外框、內容與超界提示；放開後提交一次變更，可一步復原。

外框可調整寬高比；畫面另提供「符合畫面」、放大、縮小。縮放檢視不修改教室尺寸。窄螢幕不會偷偷把教室變成另一個比例。

### 4. 外框改變時的內容處理

預設採「保留物件大小與相對中心的位置」：以教室中心為參考，增加外框只增加周圍空間，不拉扁黑板、老師桌或桌組；網格版保留行列、座位 ID 與排位，以現有座位區置中呈現。

貼牆標記隨牆移動，保留所在邊與沿牆相對位置。自由放置的老師座位與桌組維持原大小和相對中心位移。縮小到容納不下時，用紅色虛線標示超界，不靜默裁切、不刪除或隨機搬動物件；完成編輯前須移回、調整物件，或恢復足夠外框。

另提供明確命名的「等比例縮放全部內容以放入外框」操作，作為處理超界的選項；使用單一縮放倍率，保留各物件比例並置中。不能以寬、高兩個不同倍率強行填滿，避免圖形變形。字級與操作把手不隨之縮到無法使用。

外框本身不代表實際通道寬度，仍保留現場確認動線的既有提醒。標記不改寫座位鄰接圖；若操作同時移動了實際桌組，則必須沿用既有鄰接確認流程。

       │         □──────────────□               │

       └────────────────────────────────────────┘

進入展示模式時隱藏所有編輯工具、把手、參考線與選取框。展示結果與編輯預覽使用同一套幾何資料，避免手機、投影與管理畫面位置不同。

## 五、技術設計與資料相容

1. **統一邏輯座標**：教室形狀記錄寬高；物件使用同一座標系的中心位置、寬高與角度。畫面以單一倍率縮放，加上置中偏移。指標座標須反算此倍率與偏移，不能把瀏覽器像素直接存成教室位置。
2. **共用標記層**：網格與自由桌型共用標記渲染層，與座位層共用教室參考框。標記層空白區不攔截事件，只有物件及控制點可互動；展示時整層唯讀。
3. **建議資料模型**：班級狀態新增 `classroomGeometry`，包含局部 `schemaVersion`、`bounds` 與 `markers`。標記記錄 `id/type/x/y/width/height/rotation/visible`，貼牆狀態另記錄邊與沿牆比例。標記不放進 `roomLayout.tables`，讓網格教室也能使用。
4. **持久化同步調整**：更新載入正規化、匯入驗證、序列化、班級複製、班級紀錄、復原與可攜式匯出。完整檔案是否升版，實作前依現有 v5 相容策略決定；必須明確保證舊程式不會誤讀新幾何。不能只增加前端欄位而讓儲存流程丟棄它。
5. **舊設定遷移**：將舊四邊位置、偏移與大小轉為新物件，保留隱藏狀態。使用固定基準畫布換算舊像素，不能依載入當下螢幕尺寸決定資料。舊手機／桌面原本使用不同長度公式，無法在所有裝置同時逐像素保留；以桌面基準與語意位置為準，列入遷移驗收。
6. **單一資料來源**：遷移後以新幾何為準，移除舊表單寫入路徑，避免更新班級設定時又把標記重設。舊欄位只供遷移辨識，不與新幾何雙向同步。
7. **整間教室旋轉**：外框寬高互換，標記中心繞教室中心轉 90°，物件角度同步調整；貼牆邊與沿牆位置一併換算。兩種版型共用此幾何函式，並確保連轉四次回到原狀。
8. **互動生命週期**：拖曳開始建立快照，移動時只更新預覽，放開才提交、儲存並新增一筆復原；Esc、`pointercancel` 與失去指標捕捉回復快照。離開頁面或切班前結束互動，避免儲存中間狀態。
9. **模組分工**：建議新增 `js/classroom-geometry.js` 負責幾何、遷移與驗證，`js/classroom-editor.js` 負責選取與互動；`ui.js` 渲染結果，`app.js` 只保留狀態整合。沿用原生 HTML/CSS 與 Pointer Events，無須引入完整繪圖框架。

## 六、手機、鍵盤與誤操作

- 手機採「先點選、再拖曳」，選中後顯示較大的控制點；只有實際操作區限制觸控捲動，不把整頁鎖死。
- 選中物件後，方向鍵微移、Shift 加方向鍵加大位移；旋轉與尺寸也能使用有名稱的按鈕及數值輸入，不能只有滑鼠把手。
- 外框控制點與旋轉把手留足間距。支援基本對齊吸附，並提供暫時停用吸附的操作。
- 表單輸入焦點內的快捷鍵不能觸發物件刪除、移動或整頁復原。
- 「隱藏」保留位置，從工具列可恢復；「重設此標記」只影響選中的標記，不清除班級或排位。

## 七、分階段工作

| 階段 | 交付內容 | 完成條件 |
| --- | --- | --- |
| 1. 共用幾何與靜態原型 | 教室寬高、標記物件模型、網格／自由桌型共用渲染與縮放 | 不同螢幕呈現相同幾何，預覽與展示一致 |
| 2. 標記直接編輯 | 選取、拖移、縮放、旋轉、貼牆、隱藏、復原重做 | 不開下拉選單與拉霸即可完成三種標記設定 |
| 3. 外框比例編輯 | 外框拖曳、常用比例、精確寬高、超界提示與等比適配 | 改寬高不拉扁物件、不遺失座位與排位 |
| 4. 資料與舊介面整合 | 舊檔遷移、班級紀錄／備份、整間旋轉、移除舊設定表單 | 舊資料可讀，新設定重開、匯入與切班後不遺失 |
| 5. 驗證與教師試用 | 桌面、手機、鍵盤及展示驗證；簡短首次使用試作 | 達成下列驗收項目後再交付 |

階段 1–3 可用內部原型逐步驗證；完整合併前必須完成階段 4，避免可操作但無法可靠保存。首版不加多選、群組、任意圖形、樓層圖或多扇門，以免再次讓核心功能被工具數量淹沒。

## 八、驗收項目

1. 老師可直接將黑板移到側牆、拉長、轉向，並把老師座位移到教室內，無須理解位置代碼與拉霸刻度。
2. 可將外框由 4:3 改成 16:9 或自訂比例；標記、桌組不變形，座位 ID、學生預排、分開規則與已排結果保持一致。
3. 縮小外框造成超界時有可理解的提示與恢復方式，不能靜默刪除、藏起內容或把超界結果當成正常完成。
4. 拖曳、縮放、旋轉、外框變更皆能一步復原與重做；取消拖曳恢復原狀。
5. 存檔重開、切班、複製、儲存班級紀錄、完整匯出與匯入，保留相同外框與標記結果。
6. 舊位置組合、隱藏標記及偏移值可遷移；無新欄位的舊備份仍可載入；無效或非有限尺寸不可使畫面崩潰。
7. 網格、自由桌型、橫式與直式皆通過整間教室旋轉；連轉四次幾何回復，沒有累積漂移。
8. 手機與桌面均能點選控制點；縮放、頁面捲動後指標仍對準物件；鍵盤可完成基本操作。
9. 展示無編輯框、操作把手、教師設定說明或預排／分開標記；移動標記不觸發學生交換、預排或資料卡。
10. 執行現有回歸測試，加上幾何與遷移單元測試、實際瀏覽器指標拖曳／觸控／鍵盤整合測試。邀請少量老師在不讀說明的情況下完成「移黑板、放老師座位、把教室拉寬」，以觀察能否自行發現操作方式，作為易用性驗證，而不只看程式測試通過。
