# 教室畫布編輯器

在教室圖上方按「編輯教室」，或由左側「在教室圖上調整形狀與標記」進入。編輯時會開啟大型獨立工作區：上方工具列、中央畫布、右側屬性；手機以「屬性」按鈕開關底部面板。按「完成編輯」返回原畫面，不需授權瀏覽器全螢幕。

## 觀看與縮放

- 首次進入只設定一次觀看倍率；選取物件、展開設定、拖曳及修改教室形狀都不會重新縮小畫面。
- 下方顯示實際倍率，支援 10%–400%。100% 是教室邏輯單位對應 CSS 像素，不代表實際物理尺寸。
- 「看全圖」檢查整體配置；「放大選取物件」將細小標記置中放大，方便拉控制點。
- 滾輪以游標為中心縮放；＋／－以畫布中心縮放。
- 選「移動畫面」，或按住空白鍵拖曳、滑鼠中鍵拖曳來平移。手機可雙指平移及縮放。
- 看全圖、平移、縮放不修改教室資料，也不新增復原紀錄。
- 圖形與其文字共用倍率；工具列和操作把手保持可點選大小。小標記只顯示必要把手，完整名稱可在屬性面板查看。

## 標記操作

- 點選黑板、門、老師座位，拖動本體改位置。
- 拖四角與四邊控制點改寬高；勾選「鎖定比例」可保留形狀比例。
- 拖上方圓形把手旋轉，或按左右轉 90°。接近直角時會吸附；按住 Alt 可略過吸附。
- 黑板與門靠近牆面時可吸附，勾選「貼牆」會隨牆面移動；老師座位預設可自由放置。
- 點「隱藏」保留原物件，之後點工具列的同類標記按鈕可恢復顯示。
- 「精確設定」可輸入 X、Y、寬、高與角度；這些數字是教室比例單位，不是公尺。
- 選取標記後可用方向鍵微移，Shift 加方向鍵移動 10 單位。Enter 或空白鍵可選取已取得焦點的標記。
- Esc 取消正在進行的拖曳；沒有拖曳時取消選取。Ctrl/Cmd+Z 復原，Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做。輸入欄位中的快捷鍵維持原生文字編輯行為。

## 教室形狀

選「教室形狀」，直接拖邊或角改寬高，也可選 4:3、16:9、1:1、3:4，或在「教室形狀長寬比」輸入寬、高兩數並套用，例如 5：3。這會改變教室整個外框形狀，觀看倍率保持原值。精確設定另可輸入實際比例單位的寬高。外框是矩形，本版不提供多邊形牆面。

調整外框時，座位區和自由放置標記保留尺寸及相對教室中心的位置；貼牆標記隨牆移動。超界時顯示紅色虛線與提示，不能完成展示。可將內容移回、加大外框，或按「等比適配內容」將內容以同一倍率縮小並置中。這不會重新抽籤，也不會改寫學生預排與分開規則。

「看全圖」與「等比適配內容」用途不同：前者只改觀看方式；後者會調整配置，放在屬性區作為進階操作。不要為了單純看清楚而按等比適配內容。

桌組、座位與通道已可直接點選、拖移、縮放旋轉及 Delete 刪除，不需先切換專用模式；詳細操作見 [繪圖物件編輯器交付說明](drawing-object-editor-delivery.md)。標記、教室形狀、桌組與整間旋轉共用編輯復原紀錄，依實際操作順序復原與重做。

## 保存與相容

首次進入新編輯器時，才將原有黑板、門與老師座位設定換算為獨立幾何物件。換算採固定基準畫布，保留邊與偏移的語意位置；舊版原本在桌面與手機使用不同像素公式，因此不承諾在每一種裝置逐像素一致。

幾何會保存於班級草稿、班級紀錄、班級複製與完整備份。目前新物件編輯與版型草稿使用 **v7** 備份，並繼續讀取 v1–v6 舊檔；只有舊幾何、尚未使用新物件資料的紀錄可維持 v6，較早班級可維持 v5。舊程式會拒絕不支援的新格式，避免悄悄丟失獨立座位、空桌與草稿。瀏覽器工作區沿用既有儲存鍵，不另建互相衝突的資料。

拖曳期間只預覽，放開才提交一次變更與復原紀錄。中斷拖曳回復原狀，自動儲存也使用拖曳前的穩定幾何。展示不顯示控制點、編輯工具、選取框或教師設定說明。

## 驗證範圍

`tests/classroom-geometry.test.js` 驗證舊位置換算、尺寸變更與適配、旋轉不變量、無效資料拒絕與 v6 儲存。`tests/classroom-editor-browser.py` 驗證實際滑鼠拖曳／縮放／旋轉、外框拖曳、鍵盤、觸控、復原重做、取消、超界、重新載入、班級紀錄、備份匯入、整間旋轉、自由桌組與展示隔離。兩者均納入既有測試入口。

新增 `tests/classroom-camera.test.js` 與 `tests/classroom-viewport-browser.py` 驗證相機座標、縮放中心、工作區面積、展開屬性時倍率穩定、文字與圖形同步縮放、純觀看不改資料、自訂外框比例，以及多種桌面尺寸與手機雙指操作。
