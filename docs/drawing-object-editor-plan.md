# 全物件直覺編輯與完成時計算配置：實作計畫

狀態：已完成第一版實作及自動化驗證。操作與交付說明見 [繪圖物件編輯器交付說明](drawing-object-editor-delivery.md)。介面名稱為「教室形狀」，核心標題為「照顧個別需要，減少不必要的干擾與標籤化」。

## 一、目標與操作流程

老師按一次「編輯教室」後，就像進入繪圖軟體：點什麼就選什麼，拖本體移動，拉邊與角調大小，拖圓形把手轉方向，按 Delete 刪除。桌子、座位、通道、黑板、門與老師座位都使用同一套操作；不必先選「桌組與通道」或開啟另一個編輯開關，也不需要輸入座標、寬高或角度。

主要流程：

**進入編輯 → 直接畫好教室、桌組與座位 → 完成編輯 → 系統計算可用座位、鄰接與男女配置的可行性 → 回到老師預覽 → 進入展示後再抽位。**

「完成編輯」負責整理與驗證可用配置，不直接公開結果、不自動進入展示，也不把教師預排或同儕分開設定顯示給學生。

## 二、現況與必須修正的底層問題

| 現況 | 目前限制 | 計畫處理 |
| --- | --- | --- |
| 標記已有拖移、縮放、旋轉；桌組另外依賴 `roomLayout.editing` 與工具選擇 | 同一畫布存在不同編輯流程 | 統一物件選取與互動控制器 |
| 桌組靠中央標籤拖動，寬高與旋轉多在表單或按鈕調整 | 不像直接操作幾何圖形 | 桌面本體可拖，選取後共用控制點 |
| `removeSeatFromSelectedTable()` 依數量減少尾端座位 | 不一定刪掉老師真正點選的座位 | 依被選取的穩定 `seatId` 精確刪除 |
| `normalize()` 移除沒有座位的桌子，並把未歸組座位加回桌組 | 空桌、獨立座位或刪除結果可能在重開時改變 | 允許空桌與獨立座位；資料正規化不再自動補回物件 |
| `setSeatCount()` 會重算整組座位位置 | 加減一席可能打亂其他手排位置 | 新增與刪除只影響指定座位；重新平均排列是獨立動作 |
| 刪除已有安排位置時常有確認視窗，修改會立即 `reconcileSeating()` | 編輯被反覆打斷，尚未完成的構圖就影響結果 | 在隔離的版型草稿內編輯，集中在完成時檢查 |
| 男女快速配置可能清除不相容的 `pin` | 可能破壞核心的特殊需要預排 | 新流程不直接套用會清除預排的舊函式 |
| 自由桌型鄰接必須另開視窗手動確認 | 完成後還要再找另一組操作 | 完成時建立鄰接；必要疑義在同一畫布就地處理 |
| 鄰接座標換算含固定 `1.45` 比例，建議連到最近兩席 | 教室改長寬比後，計算可能不等於眼睛看到的距離 | 與渲染共用世界座標，重設鄰接計算方式 |

相關程式：`js/classroom-editor.js`、`js/room-layout.js`、`js/app.js` 的桌組操作與鍵盤事件、`js/seating-constraints.js`、`js/constrained-arranger.js`、`js/seat-engine.js` 的 `applyGenderPattern()`。

## 三、所有物件共用的操作

### 選取與拖拉

| 操作 | 結果 |
| --- | --- |
| 點桌面 | 選整個桌組，包含附著座位；狀態列顯示例如「桌組，4 個座位」 |
| 點座位 | 只選該座位，優先於背後桌面，不必先解除群組 |
| 點黑板、門、老師座位、通道 | 直接選取該物件 |
| 點教室邊界 | 選「教室形狀」，顯示調整長寬的控制點 |
| 拖物件本體 | 移動選中的物件；不再要求抓到中央標籤 |
| 拉邊或角 | 改變尺寸；Shift 可暫時鎖定比例 |
| 拖旋轉把手 | 連續旋轉，接近直角時吸附；角度只作即時提示 |
| 點空白 | 取消選取 |
| 空白鍵拖曳、滑鼠中鍵或雙指 | 移動畫面，不改物件位置 |

教室形狀仍是矩形，支援直接拉寬、拉高；本期不擴充任意多邊形牆面。工具列保留的工具主要用於新增物件與平移，不是操作既有物件的前置開關。

### 多選與整體調整

- Shift 點選加入／移除物件，拖空白處可框選；按住空白鍵則平移，避免混淆。
- Ctrl/Cmd+A 選取所有可編輯內容。教室形狀是容器，不包含在一般全選刪除內。
- 多選後可整批移動、旋轉、等比例縮放、複製、刪除及對齊；桌組與其座位不能被重複計算一次。
- 整批縮放預設同一倍率，保留物件形狀；座位尺寸下限與互相重疊以視覺提示處理。
- 方向鍵微移，Shift 加方向鍵加大位移；Ctrl/Cmd+Z 復原、Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做。
- Esc 先取消當次拖曳，再按一次才取消選取。文字輸入與可編輯欄位有焦點時，快捷鍵維持文字編輯行為。
- 觸控提供同義的就地「複製／刪除」工具，不能只依賴鍵盤 Delete。

## 四、桌組與座位怎麼調整

### 桌組大小和方向

桌組控制點直接調整桌面尺寸；附著座位隨桌組變換位置與方向，但椅子的圖形不因桌面拉長而被拉扁。縮放桌子不自動增減座位數。圓桌預設保留圓形；矩形與 U 型桌各使用對應的幾何控制點。

U 型的開口方向用可拖動的方向控制點調整，桌臂厚度用形狀控制點調整；圓桌座位環的距離也以拖拉控制點調整。這些進階控制只在選中對應桌型時出現，不先露出一堆表單。

旋轉桌組會帶著附著座位一起轉，座位的局部角度仍保留；文字反向補償，維持易讀。拖曳過程顯示對齊、等距與角度參考線，不持續彈提示視窗。

### 新增、刪除與移動座位

- 桌邊顯示淡色的「＋座位」預覽，點一下或從座位工具拖入即可新增；不必輸入每邊人數。
- 新增只分配一個新座位 ID，不重排其他既有座位。
- 座位可直接拖到同一桌的另一邊、拖到別桌，或拖到空白處成為獨立座位。拖入目標桌時先高亮預覽，放開才完成歸屬。
- 「沿桌邊平均排列」作為選中桌組後的就地選項，只在老師主動使用時重排。
- 獨立座位是合法物件；日後重新開啟不能被自動吸回某張桌子。
- 點座位按 Delete，只刪掉那一席，不用減少數量的方法猜測要移除哪一席。

新增物件可使用小型圖形工具列，選桌型後在畫布點放或拖出尺寸；這是「建立新物件」的操作，不是選取既有桌組之前必須開啟的模式。

## 五、Delete 的明確規則

| 選取內容 | Delete／Backspace 的效果 |
| --- | --- |
| 單一座位 | 刪除該 `seatId` 對應的座位 |
| 桌組 | 刪除該桌面及其附著座位，事前由選取輪廓與狀態列明確表達影響範圍 |
| 獨立選中的桌面 | 就地選單「只移除桌面、保留座位」，座位變為獨立座位 |
| 通道 | 刪除該通道物件 |
| 黑板、門、老師座位 | 隱藏該標記，保留可恢復的物件設定 |
| 多選／全選 | 對選中內容執行同一筆刪除，排除重複的父子物件 |
| 教室形狀 | 不刪除容器，提示它是編輯範圍；調整大小請拉控制點 |

刪除立即呈現，顯示簡短「已移除桌組及 4 席｜復原」，不每次詢問確認。復原必須一次還原桌子、座位、ID、歸屬及草稿中的安排關係。

允許暫時刪到沒有桌子或沒有座位，保持畫布草稿；不因現有「至少留一桌／一席」限制而阻止構圖。完成時若容量不足，再標出差幾席。

已安排的學生不會隨座位一起刪除。被刪除座位上的預排轉為「需要重新指定位置」，保留學生身分及預排意圖；不能靜默取消特殊需要預排。同儕分開規則仍依學生身分保留，不因物件刪除消失。

## 六、編輯時只畫，完成時再計算

### 編輯期間

編輯區操作隔離的 `layoutDraft`，不立即改寫上一次已完成的教室與排位。草稿可自動暫存，重新開啟可繼續；不能把尚未通過檢查的草稿當成正式展示結果。

拖曳時只做輕量提示，例如超界、重疊與對齊，不反覆執行男女配置或完整排位求解。不讓每次拖動都觸發已有結果的重新安排。

### 按下「完成編輯」

以當時草稿建立快照，依序完成：

1. **幾何檢查**：物件尺寸有效、ID 唯一、座位歸屬合法、沒有不可接受的重疊或超界。提示直接在畫布定位問題，提供「前往下一處」。
2. **容量與預排對應**：計算需要實體座位的學生、可用席數、空位與失去座位的預排。若有預排需要補位，在同一畫布讓老師把待安排學生放回適當位置。
3. **實際位置計算**：以教室世界座標套用桌組與座位的旋轉、縮放、局部位置，建立所有座位的真正中心與邊界。
4. **鄰接與桌組建立**：由上述位置計算前後、左右、斜向相鄰與桌組關係，供不能坐在一起的規則使用。必要時就地確認少量有歧義連線。
5. **男女與規則聯合規劃**：沿用老師已選的策略，或預設盡量均衡；在保留預排與必須分開等硬條件下，檢查配置是否可行。
6. **原子提交**：只有檢查通過、資料仍與快照一致、儲存成功，才將草稿提交為正式教室。回到老師預覽並顯示「配置可用，可開始抽位」。

計算中顯示簡短階段進度，可取消；不長時間鎖住瀏覽器。名單、預排、規則或版型在計算時改變，舊計算結果必須作廢。

## 七、男女安排與同儕分開如何配合

### 不能被自動放寬的條件

- 一人一席、有效學生與有效座位、足夠容量。
- 教師已指定的預排位置與明確的座位性別限制。
- 啟用的「不相鄰」與「不同桌組」規則。

### 可由系統優化的偏好

- 男女盡量交錯、各桌盡量均衡。
- 空位盡量分布合理、保留合法的既有位置。

預設的自動男女規劃是偏好，不可為追求漂亮交錯而取消預排或拆掉分開規則。若教師另指定嚴格男女策略，則將它列入硬條件，衝突時明確說明，而不是默默放寬。

性別沿用已有名單資料與既有座號規則，不根據姓名猜測；資料不明或不適用者保持不限。編輯畫布不要求老師逐席點男／女，也不要求輸入各桌人數。

完成時建立「可行性結果與自動男女偏好」，不直接把特定學生抽到特定位置。可行性求解內部使用一份解作為驗證，但不把它當成正式抽籤結果；公開抽位仍由後續抽籤流程重新求解。

建議以 `genderPlan` 表示「系統建議」與「教師固定限制」的來源差別。自動偏好不直接寫成每席不可變更的硬限制，避免過早限制男女分布，讓原本能滿足的分開規則反而無解。

## 八、鄰接計算必須升級

目前最近兩席的建議連線無法完整代表前後、左右及斜角，固定 `1.45` 又不符合可調長寬比的教室。新流程必須與渲染共用 `worldGeometry`，不能另寫一套近似座標。

- 規則網格保留明確八方向鄰接語意；移動、旋轉整張配置後應得到等價關係。
- 自由桌型依座位邊界、中心距離、朝向、桌組與同桌排列順序建立候選鄰接；不是每席無條件只連最近兩個。
- 距離門檻使用座位尺寸／間距的比例，不使用螢幕像素；放大、平移、手機或桌面不能改變鄰接結果。
- 大間隔、跨桌接近、通道邊界等情況，以明確規則處理，不將所有通道圖形一律視為隔音牆。需要教師判斷的部分在完成流程內高亮，點連線切換即可，不要求另外開一張技術表格。
- 獨立座位視為各自的單席桌組，讓不同桌組規則有明確意義；遺失桌組參照是資料錯誤，不能假裝成獨立座位來讓規則通過。

首版必須用固定幾何案例校準鄰接規則；距離門檻與各特殊情況在實作前定義成可測試的規格，不宣稱單靠最近距離就能辨識所有真實教室互動。

## 九、失敗時怎麼呈現

| 情況 | 老師看到的回應 |
| --- | --- |
| 少 2 個座位 | 畫布顯示「還需要 2 席」，可直接點桌邊新增 |
| 有預排失去座位 | 高亮待安排學生與可用位置，不刪除預排意圖 |
| 重疊或超界 | 標出物件，點提示直接定位與放大 |
| 預排的兩人違反分開規則 | 同時高亮兩個位置與規則，讓老師移位或自行修正規則 |
| 證明無解 | 顯示可核實的衝突資訊，不聲稱已找到最小衝突集合，除非程式有實際計算 |
| 計算逾時 | 顯示「尚未找到符合配置」，保留草稿與上次有效配置，可重試或調整；不能宣稱一定無解 |
| 儲存失敗 | 保留草稿與目前編輯畫面，不能假裝完成並覆蓋原資料 |

這些問題集中在完成流程處理，不以每次移動都跳對話框的方式打斷編輯。

## 十、程式與資料設計

1. **統一選取模型**：`selection = [{ kind, id }]`，識別桌組、座位、通道、標記與教室形狀。命中檢測以座位優先於桌面，再依層級處理；刪除與多選先清除重複父子關係。
2. **統一幾何服務**：`worldGeometry` 提供渲染、命中、吸附、控制點、重疊與鄰接共同使用的世界座標；沿用相機的 `screenToWorld`／`worldToScreen`。
3. **桌面與座位分離**：桌面尺寸、座位尺寸與座位數是不同概念。附著座位保留局部座標與角度；獨立座位有明確標記，座位 ID 與學生身分不能混用。
4. **統一命令與復原**：新增、變換、刪除、歸組、解組、複製、對齊皆為命令；一段拖曳或一次多選刪除只是一筆。復原包含位置、歸屬、預排與草稿安排，純相機操作不進入資料復原。
5. **獨立完成控制器**：集中處理幾何驗證、容量、鄰接、男女偏好、受限求解與提交，不散落在各拖曳事件中。
6. **計算失效簽章**：包含幾何、座位歸屬、學生身分與性別資料、預排、分開規則、策略與演算法版本。任何一項改變都不可沿用舊可行性結果。
7. **資料版本與遷移**：預計需要新版 `roomLayout` schema，解除空桌與獨立座位限制；完整備份依相容性升版，讓舊程式明確拒絕不支援的資料。現有 v1–v6 仍須可讀，不在遷移時任意補回座位。
8. **草稿、紀錄與備份**：版型草稿與上次有效配置都能可靠保存；班級紀錄、複製、匯入匯出與可攜式檔案定義清楚，不因換裝置丟失正在編輯的內容。

不建議只為現有幾個按鈕補 Delete 快捷鍵就結案；選取、父子物件、座位歸屬及完成流程若未統一，仍會出現刪錯席、刪除後補回、縮放後計算不一致等問題。

## 十一、分階段交付

| 階段 | 交付 | 完成標準 |
| --- | --- | --- |
| A. 選取與命令基礎 | 取消桌組專用前置模式，統一選取、Delete、復原與編輯草稿 | 點選後可直接刪除，重開不補回，既有有效配置不受半完成草稿影響 |
| B. 物件幾何 | 桌組、座位、通道共用控制點；附著、獨立座位與移桌 | 全程不輸入數字即可調大小、方向與座位位置 |
| C. 多選與整體操作 | 框選、全選、複製、對齊、整批變換與觸控等效操作 | 父子物件不重複移動或刪除，一步能復原全部 |
| D. 完成時計算 | 幾何、容量、鄰接、男女偏好與分開規則聯合檢查 | 成功原子提交，失敗能就地修正；逾時、取消不丟草稿 |
| E. 美編與整合驗收 | 套用美編層級、整理屬性工具與新教學 | 不因新功能重新塞滿按鈕，教室圖仍是畫面主體 |

各階段可做內部預覽，但正式替換前至少完成 A、B、D 及資料遷移，避免只做到好拖拉，卻不能可靠儲存或用於規則排位。

## 十二、驗收清單

- 進入編輯後直接點任何桌組、座位、通道或標記即可操作，沒有第二個「開始編輯」或切換物件種類的門檻。
- 選中任意一席按 Delete，精確刪除該席；刪最後一席、最後一桌與全選刪除皆能保持合法草稿，重開不補回。
- 縮放桌面不改座位數、不拉扁椅子；新增一席不打亂其他手排位置；跨桌拖曳後歸屬與規則計算正確。
- 旋轉、移位、改教室長寬比後，渲染座位中心與求解使用的位置一致；不同相機倍率及裝置的鄰接結果相同。
- 完成時計算性別偏好、容量與分開規則；不能清除預排、刪除學生或默默放寬硬條件。
- 刪除預排所在座位會保留待重新指定的預排意圖；未解決前不得當成正式完成。
- 測試空桌、獨立座位、U 型開口、圓桌、狹長教室、接近與分離桌組，以及八方向網格鄰接。
- 測試已知有解、已知無解、逾時、取消、計算途中改名單／改規則、儲存失敗，以及舊檔遷移與紀錄還原。
- 表單內 Delete、方向鍵、Ctrl+A 只能編輯文字；手機能以選取後的就地工具完成相同行為。
- 展示只公開中性排位結果，不顯示預排、同儕分開名單、教師設定理由或編輯控制點。
- 以「搬桌子、拉大桌子、旋轉、刪一席、加回一席、完成編輯」作為教師試用任務，確認不必先學多個操作模式或輸入數值。

本計畫已完成第一版實作。真實教室鄰接判斷與首次教師試用仍需現場驗證；程式的自動鄰接圖可在原有鄰接檢視工具中檢查與調整。
