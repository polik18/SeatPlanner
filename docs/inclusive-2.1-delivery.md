## R1：v5 資料與穩定身分

- 修改：`constants.js`、`class-data.js`、`storage.js`、`student-draw.js`、`app.js` 與 class-library 測試。
- 完成需求：永久班級 ID、學生身分對照、學年度／學期、具名版本快照、單班與工作區格式、各班抽學生輪次、v1–v4 讀入遷移。
- 資料行為：新鍵 `classroom-seat-master:v5`。讀舊鍵後寫新鍵，保留舊值；有損壞 v5 時不回退舊資料或覆寫損壞原值。具名快照不遞迴包含歷史列表。舊基線時間標為未知，不虛構原建立時間。
- 操作路徑：開舊工作區或匯入舊 JSON → 正規化 → 在新版保存；完整新備份標 v5，無無聲降版。
- 自動化：class-library 單測覆蓋遷移、身分、序列化、快照不變性、去重、配額失敗及損壞資料；既有 storage 相關測試調整為 v5。
- 證據：改號可保留原身分及規則；新學生不繼承退休身分規則；抽學生歷史可對應改號，並隨班保存與備份。
- 限制：仍使用瀏覽器 localStorage，容量有限；不承諾永久保存或跨裝置自動同步。舊版抽學生只有單一儲存槽，僅接回與目前班級簽章匹配的資料，無法重建已覆寫的其他輪次。
- 依賴：保全先行；穩定學生身分是 R3／R4 配對規則的基礎。教學 metadata 仍獨立。

## R2：老師可保存、重開的班級紀錄

- 修改：`class-records-ui.js`、首頁、樣式與 app 協調。
- 完成需求：我的班級、具名儲存、接續草稿、歷次版本預覽／還原、單班下載、學期欄位、封存篩選、刪除紀錄、複製內容選項、同 ID 匯入更新／副本選擇。
- 資料行為：自動暫存不等於具名紀錄；相同業務內容與學期不重複新增。還原先保存目前草稿，恢復整份版本及學期；更新匯入先保存舊版本。寫入失敗不將未保存紀錄提交到工作區。
- 操作路徑：頁首「儲存班級」→ 填名稱 → 儲存；「我的班級」→ 選版本 → 預覽並開啟；班級面板「備份此班完整檔案」。
- 自動化：class-records 瀏覽器測試使用真正關閉／重啟的 Chromium 磁碟 profile，並在乾淨瀏覽器還原單班檔；涵蓋配額回滾、學期、封存、複製、身分確認與匯入更新。
- 證據：瀏覽器重開後具名版本、草稿、規則與抽學生輪次仍可讀；版本還原保留之前草稿；複製班級不沿用另一班抽選輪次。
- 限制：下載為瀏覽器檔案下載，不表示自動寫回指定本機檔案。歷史不自動清除，配額滿時需備份後自行清理；介面提示班級數及序列化資料估計大小。
- 依賴：R1；保存班級不包含本次未要求的教學日誌或個別敏感觀察欄位。

## R3：同儕限制與受限制隨機求解

- 修改：`seating-constraints.js`、`constrained-arranger.js` 及對應單測。
- 完成需求：不相鄰八方向、不同桌組、多人配對、固定預排衝突、候選座位回溯搜尋、取消、預算截止、最終全結果驗證。
- 資料行為：配對綁定學生身分，A–B/B–A 去重。已退出名單或不需實體座位的相關規則保留但暫不參與實體座位求解。無限制時沿用原洗牌流程。
- 操作路徑：設定規則後按「依目前規則重新抽位」或正常展示後抽位。
- 自動化：小型案例與窮舉可行性比對、重複隨機抽位、性別席次與固定位置的組合、30 人案例、無解／節點預算／中途取消。獨立結果驗證器再查完整結果。
- 證據：一列三席的限制兩人可坐兩端；一列兩席禁止相鄰會拒絕；2×2 網格包含斜角；固定衝突不偷偷移座。同步舊抽位入口遇新規則會拒絕，避免意外繞過。
- 限制：隨機化搜尋順序不等於所有合法結果均勻抽樣。預設計算預算為 150,000 節點／約 3 秒，分段讓出畫面；超限顯示尚未找到，不誤稱已證明無解，不保證任意大量規則皆能即時找到結果。
- 依賴：R1 身分對照、現有性別座位／容量檢查。活動任務分組不套用日常座位配對。

## R4：規劃介面與自由教室鄰接

- 修改：`separation-ui.js`、教師規則面板、鄰接圖及身分對照視窗。
- 完成需求：搜尋與選兩位學生、編輯／停用／刪規則、狀態與衝突提示、SVG 鄰接預覽、增刪連線及確認、名單改號／改名的歧義對照。
- 資料行為：網格固定八方向；自由教室需教師確認鄰接邊，依邏輯座標建議，不依 viewport 像素。桌型、位置、座位與旋轉改變使舊確認失效；縮放及語言不影響判定。
- 操作路徑：教師頁「同儕分開安排」→ 選 A/B → 規則 → 新增／更新；自由桌型先按「預覽／確認座位鄰接圖」。
- 自動化：圖形與旋轉失效單測；瀏覽器檢查未確認時不抽位、確認後可求解、改布局後重新確認，不同桌組規則可重載保留。
- 證據：圓桌建議包含首尾鄰近；教師可修正對坐或跨桌連線；單一桌的不同桌組規則不會假成功。
- 限制：建議圖仍需教師確認實際教室，圖示不是公尺距離、法規通道驗證或個別需要推論。
- 依賴：R1／R3；無法辨別原學生或新學生時由老師明確選擇，不僅憑姓名自動認人。

## R5：全流程防繞過、回歸與交付

- 修改：app、manual-seating、student-draw、公開渲染、測試入口、README、指南及本報告。
- 完成需求：抽位候選揭曉前檢查當前條件；手排、交換、預排及展示共同驗證；公開渲染另有守門，幾何／復原造成失效會返回教師頁。規則編輯不破壞舊結果，可保存衝突規劃但不公開為合格排位。
- 資料行為：教師完整檔保留配對與版本；展示時清空教師規則內容與學生 UUID 選項，去敏分享不含 UUID、規則或歷史。新資料不覆寫舊 v4 儲存鍵。
- 操作路徑：建班 → 儲存／重開 → 設分開規則 → 抽位／手排 → 展示 → 單班備份還原。
- 自動化：10 份 Node + 6 份 Chromium 瀏覽器腳本通過；包含原 11 份測試回歸、file://、無外部請求、手機尺寸、真實觸控、鍵盤與新功能。
- 證據：連續重抽全數通過配對檢查；相鄰固定預排被拒；手排／交換無法引入配對衝突；取消計算保留原狀；公開 DOM 與去敏檔沒有學生 UUID 或配對規則。測試輸出及截圖隨文件保存。
- 未完成驗收：至少三名真實新手教師試用、實體裝置、其他瀏覽器、螢幕閱讀器人工檢查及實際 GitHub Pages 部署。未虛構參與者、成功率或教學成效。
- 依賴／提交：最終版本位於 `feature/class-records-and-separation`，可用 `git log --oneline` 查分段提交。交付包與 2.0 原版分開。
