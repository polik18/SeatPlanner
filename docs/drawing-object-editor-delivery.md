# 繪圖物件編輯器與展示浮動操作列

## 本次交付

展示模式下，抽籤操作改為固定浮動列，不再放在座位表最下方。無論頁面捲動到哪裡，「開始抽籤／重新抽籤」及「全手動排位」都保持可見；抽籤動畫時顯示直接揭曉。手機提供安全邊距，並避免與回首頁按鈕重疊。

## 直接操作物件

按一次「編輯教室」即可開始。桌面、座位、通道、黑板、門與老師座位皆可直接選取，不必另開桌組編輯模式。

- 拖本體移動，拉邊角控制點改大小，拖圓形控制點旋轉；圓桌保持圓形。
- 點座位只選該席；點桌面選整個桌組及其附著座位。拉大桌子不會改座位數或拉扁椅子。
- Delete／Backspace 刪掉所選物件；桌組連同附著座位一起刪除。「只移除桌面，保留座位」則把座位轉為獨立物件。
- Shift 點選多選，拖空白處框選；Ctrl/Cmd+A 或「全選物件」選全部內容。教室形狀是容器，不會被全選刪除。
- 多選可整批移動、等比例縮放、旋轉、對齊、複製與刪除。父子物件不重複處理。
- Ctrl/Cmd+D 複製，Ctrl/Cmd+Z 復原，Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做；Esc 取消尚未提交的拖曳。
- 在表單輸入時，Delete、方向鍵與 Ctrl/Cmd+A 維持文字編輯用途。
- 觸控以就地按鈕執行刪除、複製等動作，雙指平移與縮放保留。

## 新增與調整座位

可在工具列新增方桌、圓桌、U 型桌、座位及通道。選中桌組時，桌邊會出現「＋」入口。新增一席不重排其他已放好的座位；系統會選擇可用的間隔位置。獨立新增座位會盡量避開既有物件，若空間不足仍需老師調整。

座位可以直接拖到別桌或空白處，放開時更新歸屬。「沿桌邊平均排列」是明確的選用操作，不會因一般移動或增減一席自動觸發。U 型開口與桌臂厚度、圓桌座位環距離也有圖形控制點。

允許草稿刪到空教室、保留空桌及獨立座位。重新載入不會自動補回已刪除物件，也不會把獨立座位塞進別桌。

## 草稿與預排保護

編輯區使用版型草稿。自動暫存會分開保存上次有效配置和目前草稿；「稍後繼續」返回上次有效配置，下一次編輯可接續草稿。

刪除座位不刪除學生。若刪掉預排所在座位，學生會出現在「預排需要重新指定」區；先點該學生，再點新位置即可重新指定。未處理完不能正式完成，也不會默默清除預排。同儕分開規則持續依學生身分保留。

拖曳中的自動儲存使用穩定的拖曳前快照，避免把半完成變形寫成有效配置；未完成配置不會覆蓋原排位。

## 按下完成編輯後

1. 檢查有效物件、容量、超界、座位／桌面重疊與主要通道占用。
2. 檢查是否仍有失去位置的預排，保留所有教師固定條件。
3. 使用實際世界座標計算鄰接與桌組關係，不再以固定螢幕比例估算。
4. 規劃男女均衡偏好，檢查預排、性別限制、不相鄰與不同桌組規則可否同時滿足。
5. 只有檢查與儲存都成功，才提交為有效配置；取消、逾時、無解或儲存失敗都保留草稿。

完成編輯不等於抽籤，不直接公開學生配置。仍需進入展示後按抽籤；系統重新求解，保留硬性規則。男女自動建議是偏好，不會為了交錯而清掉預排或放寬分開規則。教師已明確指定的性別座位限制仍是硬條件。

獨立座位視為各自的單席桌組。「不同桌組」與「不相鄰」是不同條件，不能把前者當作距離限制。自動鄰接依幾何推算，老師仍可在既有鄰接檢視工具檢查與調整；真實動線及桌距需現場確認。

## 資料與相容

新物件教室採 `roomLayout.version = 3`。含新物件或版型草稿的完整備份採 **v7**，避免舊程式讀入後丟棄空桌、獨立座位或草稿。舊版 v1–v6 匯入保留；未使用新資料的舊班級仍沿用原本可支援的輸出格式。

主要新增模組：`drawing-scene.js`（資料與世界幾何）、`drawing-objects.js`（選取與命令）、`layout-planner.js`（完成檢查與聯合規劃）。班級紀錄、複製、備份、匯入及復原流程一併整合。

## 驗證

`tests/drawing-scene.test.js` 驗證精確刪除、空教室、ID 與歸屬、物件座標、群組複製、v7 草稿、八方向鄰接及旋轉不變性、預排衝突與完成計算。

`tests/drawing-editor-browser.py` 驗證浮動按鈕、手動入口、直接桌組拖曳／縮放／旋轉、Delete、全選、復原、草稿隔離與重新載入、儲存失敗、預排重新指定，以及完成後的實際抽位。兩者均納入完整回歸入口。

真實教師首次使用試用及完整無障礙稽核尚未進行。美編研究原型仍是獨立提案，未把整份原型直接替換正式首頁。
