# 全手動排位：操作設計與驗收

老師可按頁首或座位圖的「全手動排位」，不必先抽籤。核心操作是「選學生 → 點座位」。每次排好後預設接續下一位待排學生，老師只要繼續點選想安排的位置；也可以取消自動接續，逐一指定人選。

## 為什麼採用這個流程

現行「事先安排」每次點座位都需開啟指定學生視窗，且最終流程仍以抽籤為主。「調整結果」只能在抽籤後交換座位。新增的手動模式把學生名單放在座位圖旁邊，讓老師可依學生需要先後安排，不必反覆開關選單。

點選是主要操作，桌面拖曳為補充。觸控使用相同的兩次點選；鍵盤可用 Tab、Enter／空白鍵排位。此為本次產品設計判斷，尚未進行教師使用者訪談或現場可用性研究。

## 操作約定

- 首次進入沿用目前完成結果；沒有結果則沿用預排位置。沒有預排就是空白表。按「全部移回待排」可清空手動草稿，並可復原。
- 待排名單可搜尋座號／姓名，切換全班名單可直接選已排學生。每個人只會出現在一個座位。
- 未排學生放到有人座位：原學生移回待排並自動選取，讓老師接著安排他。
- 已排學生放到有人座位：兩人交換；放到空位：移動。選已排學生後按「移回待排」可暫時移出座位表。
- 「復原／重做」保存本次編輯最近 100 步；支援 Ctrl／Cmd+Z 與 Shift+Z。重載、匯入、修改名單／桌位或旋轉後重新計算操作歷史，避免復原錯誤座標。
- 草稿自動保存至目前瀏覽器，包含在 JSON 匯出；未完成草稿與上一次完成結果獨立。重載或匯入可接續手動排位。
- 教師可自由決定位置，抽籤性別限制和固定標記不限制手動操作；走道不能坐人。既有抽籤規則保留，重新抽籤仍會檢查規則。
- 完整安排所有有效學生後，「完成並展示」直接呈現結果。缺號不需安排，額外桌位可留白。完成結果可再調整、重載與匯出。
- 增減網格或名單時保留仍有效的草稿位置；消失的桌位釋出学生，刪除的座號不再保留。旋轉教室會同步轉動草稿。
- 改班名／展示內容不清除完成結果；改名單或座位規則沿用原程式的結果失效行為，手動草稿仍會清理後保留。

## 驗證方式

`node tests/manual.test.js` 驗證資料清理、缺號、走道、移動／交換、不重複與草稿序列化；`python tests/manual-browser.py` 以 Chromium 實際操作草稿、搜尋、拖曳、鍵盤、復原、匯入匯出、旋轉、完成展示及五種尺寸的點選／觸控。Python 測試需事先安裝 Playwright 及 Chromium。原有引擎與抽籤時序測試一併執行。
