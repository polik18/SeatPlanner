# 座位關係與教室邊框修正

日期：2026-11-08。

## 使用方式

1. 開啟「編輯教室」後自由移動椅子，完成編輯。男女交錯的橫排、直行與棋盤配置改依目前位置判斷，不再依原座位行列編號。
2. 自由畫布上的男女配置按鈕每次更新；有桌組時也提供桌邊順序交錯，獨立席不會漏算。
3. 分開安排使用目前位置的鄰接關係。鄰接預覽中人工新增或移除的線會保存，重新進入並完成編輯不會被自動建議覆蓋。
4. 拖曳椅子保留原桌組。選取單椅後，可在屬性中的「座位歸屬」指定桌組或改成獨立席。
5. 編輯模式直接點教室任一邊框，即可顯示八個尺寸控制點。圖上顯示寬高與常用比例；原有精確尺寸、鎖定比例、超界提示及復原功能保留。選取工具下可操作，平移工具下仍為平移。

## 計算與保存

邏輯行列由 `drawingScene.logicalCells()` 統一取得，容許小幅錯位，座位 ID 與原行列資料保持原值。桌組順序使用桌面局部座標，獨立席使用目前行列排序。自由教室鄰接由 `seatingConstraints.refreshTopology()` 計算；求解及驗證都走同一入口。

`seatTopology` 保存自動圖及人工 `overrides.add/remove`。完成編輯合併人工修正並清除已刪除端點；舊自動圖重新計算，舊人工圖轉換後保留。資料沿用既有 v7 備份、紀錄及草稿保存途徑，並增加連線格式與重複資料驗證。

`genderPlan.source = teacher-pattern` 記錄教師選擇的配置模式，後續完成教室時依新位置重新套用；不再一律覆寫成自動平衡。重新套用若與預排衝突，保留預排並回報無法完成。

目前行列推導以畫面橫直方向與座位中心群聚為準，適合可辨識行列的排列；不規則桌型可選桌邊順序。鄰接仍是示意幾何推導，並非實際公尺距離。人工修正會跨移動保留，預覽提示教師移動後檢查。此次未加入強制吸附、任意多邊形教室或通道阻隔的新語意。
