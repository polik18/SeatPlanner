# Inclusive 2.1 操作指南

直接雙擊 `index.html`，不需要伺服器、帳號或雲端。初次仍可使用五步導覽。原有抽學生、任務分組、手排與自由教室繼續使用。

## 儲存與開啟班級

1. 新增班級，填班名與名單，選填學年度及學期。
2. 按頁首「儲存班級」，輸入例如「11 月座位」的名稱，再按「儲存紀錄」。完整狀態會成為可重開的版本；相同內容不重複新增。
3. 頁首的「草稿已暫存」只表示目前修改已在瀏覽器暫存，與具名紀錄不同。未完成或有規則衝突的規劃可先儲存，但不能當作符合規則的完成結果展示。
4. 下次按「我的班級」→「繼續編輯」接續草稿，或選歷次紀錄→「預覽並開啟紀錄」。開舊版會還原整份名單、教室、規則、排位及學期，同時先保留目前草稿。
5. 「備份此班完整檔案」下載單班 v5 JSON；「完整本機備份」下載所有班級。在別的裝置／瀏覽器用「匯入設定」開啟。

同一 v5 班級再匯入時，可選「更新原班」或「另建副本」。更新先保留目前版本；不是只看班名覆蓋。複製班級預設只複製教室，可另選連名單及規則一起複製。封存保留紀錄，可在「顯示封存班級」找回；刪除紀錄前須確認。

本機保存仍受瀏覽器資料清除、權限及容量影響。發生儲存失敗時原已存值保留，先下載備份，再自行選擇清理版本。具名版本不自動輪替刪除；本次頁面的即時「復原資料操作」不能取代持久備份。

## 先設定誰和誰分開

1. 在教師頁打開「同儕分開安排」，用搜尋或清單選學生 A、B。
2. 勾選「不相鄰（八方向）」或「不同桌組」，可兩者並用，再按「新增／更新規則」。反向輸入同一對不會重複建立。
3. 可為同一學生設定多位配對，也可編輯、停用及刪除。規則不要求填個別理由，不會投影。
4. 按「依目前規則重新抽位」。所有啟用硬限制通過才揭曉；無解會提示條件衝突，不會擅自移動固定座或放寬規則。計算逾時表示尚未找到，不等於已證明無解；可重試或調整。計算期間可取消，原排位保留。

網格不相鄰包含左右、前後與斜角。一列三席，兩位限制學生坐在兩端即可，中間可坐別人或留空；完整走道不會被壓縮成相鄰。

## 自由桌型的鄰接圖

不同桌組依桌組歸屬檢查。若只有一張 U 型大桌，兩位學生要求不同桌組就可能無解；請改用符合需求的鄰接規則或增加桌組。

自由桌型的不相鄰必須按「預覽／確認座位鄰接圖」：線段代表視為相鄰。檢查系統建議，可取消勾選移除連線，或選座位 A、B 新增連線，再確認。圓桌建議包含首尾近鄰，但對坐與跨桌鄰近仍由老師檢查。線段不代表實際公尺距離，不作通道合規認證。

改桌型、座位、位置或旋轉後，如圖已不符合當前布局，就需要重新確認；縮放、語言或換裝置不會改鄰接定義。網格預覽固定採八方向，不可自行取消線段。

## 固定預排、手排與舊結果

兩位被限制的學生若預排在相鄰座位，會拒絕第二項衝突安排。手排放置及結果交換也不能新增配對違規；完成手排及展示前再次驗證。有規則待確認時，手排頁會顯示提示並提供「回到規則設定」。

新增規則後若舊結果不符合，舊排位會保留作歷史或草稿，不能直接展示為合格結果；用教師頁「依目前規則重新抽位」重新計算。展示期間復原／旋轉導致條件失效，會回到教師頁處理。

不需實體座位或已離開目前名單的學生，其規則保留並顯示暫不參與排位；恢復需座位後重新檢查。這些配對只限制日常座位，不自動變成任務分組的禁止同組規則。

## 改座號、改名或換學生

有規則或已安排結果時，若新名單存在身分歧義，會出現對照窗。改號／姓名更正請選原學生；換成新學生請選「新學生身分」。同一原學生不能對應兩個新座號。也可從規則面板主動開「學生身分對照」。規則綁定內部身分，不會只因同名或沿用座號就套給另一個人。

若新舊學生的座號與姓名完全相同，資料本身無法判斷是否換人；實際換學生時，請主動開「學生身分對照」改選新身分，不要沿用舊規則。

## 檔案與隱私

新工作區及完整備份是 v5，可讀 v1–v4；初次遷移保留舊鍵。舊版程式不保證認得 v5 規則，不要修改檔案版本號來假裝相容。舊抽學生功能只有單一儲存槽，無法重建先前已覆寫的其他班紀錄。

完整教師檔含班級紀錄與配對規則，請妥善保存。去敏座位表只分享位置與座號，沒有姓名、學生內部 ID、配對或紀錄，也不能用來恢復完整班級。展示資料卡仍只公開座號與姓名。本次未新增班級教學日誌或敏感觀察欄位。
