# 讓融合班級的核心用途容易被發現

本次檢查發現，程式已具備預排座位、同儕分開限制與展示隱藏標記，但首頁以多種工具並列呈現；「優先安排」沒有直接說明特教生在融合班級的合理調整用途，同儕分開規則則藏在摺疊區。新手需要自行拼湊操作與用途。

本次將首頁主訊息與歡迎介紹改為「老師私下準備、全班自然揭曉」，並將兩項核心設定放在首頁步驟之前：

1. **預排個別座位**：說明視線、聆聽與動線等需求，按鈕直接進入預排操作。
2. **設定同儕分開**：說明避免互相干擾的情境，按鈕展開並定位規則表單；表單預設展開。
3. **全班展示與抽位**：明確說明預排位置保留，其餘依規則分配，全班一起揭曉，不公開預排標記與分開名單。

操作教學與中英文文字同步更新。上述介紹僅在管理介面出現，展示沿用中性座位畫面。教師應在未投影時設定，返回管理介面前停止投影；隱藏設定無法保證學生永遠不會從重複結果推測安排，因此介面不作此保證。程式不需要記錄診斷或個別安排理由。

預設名單中的三字姓名以「○」替換中間字，並標示為示範資料。只更改預設值，不覆寫已儲存的班級名單。

驗證：既有 Node 回歸測試，以及 `tests/inclusion-purpose-browser.py` 的桌面／手機入口、三字姓名遮蔽、預排與分開同時生效的重複抽位、展示隱藏標記。實際教師首次使用的理解程度仍需透過試用確認。
